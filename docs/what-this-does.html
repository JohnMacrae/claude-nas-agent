Property Agent

An autonomous Claude agent on John’s NAS for ~59 residential rentals — morning briefings, work-order inbox, Maintenance calendar, FreeAgent drafts, and Telegram ops. Decoupled from Open Brain (OB1) and personal Life Engine.

What it does How it runs Schedule Work orders Safety Ops

What it does

Morning briefing Email property summary + FreeAgent draft invoices from completed jobs.
Property checks Every 2 hours: local inbox, calendar, Home Maintenance follow-ups.
Local memory JSON under data/ — inbox, notes, invoice dedup, Telegram replies.
Telegram ops /status, /trigger, job completions (e.g. 59BC-1.5hr). Dedicated property bot.
Standalone No Open Brain MCP, no OB1 trigger dependency, no Life Engine habits/check-ins. Personal productivity stays with OB1 / the life-engine skill.
